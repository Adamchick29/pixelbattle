# Пиксель Баттл

Общее поле 256 × 256: один пиксель каждые 5 секунд. Гости наблюдают, участники рисуют после регистрации по email и паролю. Интерфейс на русском, в светлой пиксельной теме из предоставленного 



### GitHub Secrets

| Имя | Значение |
| --- | --- |
| `SSH_HOST` | IP или DNS-имя VPS без схемы |
| `SSH_USER` | `root` либо пользователь с passwordless sudo |
| `SSH_PRIVATE_KEY` | Отдельный приватный SSH-ключ деплоя в формате OpenSSH |
| `SSH_KNOWN_HOSTS` | Проверенная запись SSH host key сервера |
| `POSTGRES_PASSWORD` | Случайный пароль: 24–128 символов `A-Z a-z 0-9 _ -` |
| `REDIS_PASSWORD` | Другой пароль в том же формате |
| `MONITORING_PASSWORD` | Пароль VMUI: 12–128 печатных символов |

### GitHub Variables

| Имя | Значение |
| --- | --- |
| `APP_ORIGIN` | Например `http://203.0.113.10`; для порта 8080 — `http://203.0.113.10:8080` |
| `SSH_PORT` | Необязательно, по умолчанию `22` |
| `MONITORING_USER` | Необязательно, по умолчанию `monitor` |
